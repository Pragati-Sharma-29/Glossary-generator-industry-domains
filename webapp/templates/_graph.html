{# Reusable graph card: renders `graph_data` ({nodes, edges}) with vis-network. Expected context: `graph_data` - a dict like {"nodes": [...], "edges": [...]} where each node has {"id", "label", "group"} and each edge has {"from", "to", "group"}. Groups drive colour (see `groups` map in the init script below). Table nodes carry an extra `columns: [{id, name, term_id, ...}]` field. These are not rendered initially — a table's columns appear (with contains + definition edges) when the operator clicks the table; its aggregated definition edge is hidden for the duration of the expansion. #}
